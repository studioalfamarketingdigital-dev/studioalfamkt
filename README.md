# Studio Alfa MKT

Agência de Marketing e Publicidade 360° Full-Service em Luziânia/GO e Brasília/DF.

## Tecnologias

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Desenvolvimento

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Deploy

Deploy automático via Vercel conectado ao repositório GitHub.
